# ICS/OT Technologies Experienced in Class

[← Back to README](../README.md)

ICS613 exposes students to a range of industrial technologies, protocols, and architectures through labs, analysis exercises, and the capstone.

---

## Control System Architectures

- Distributed Control Systems (DCS)
- Programmable Logic Controllers (PLCs)
- Human-Machine Interfaces (HMI)
- Engineering Workstations (EWS)
- Operator Workstations (OWS)
- Historian Servers
- OPC Servers

## Industrial Protocols

- Modbus TCP/RTU
- EtherNet/IP (CIP)
- Proprietary vendor protocols
- OPC (OLE for Process Control)

## IT/OT Convergence Technologies

- Active Directory in OT environments
- Windows-based control system workstations
- Remote Desktop Protocol (RDP) in OT
- Domain trust relationships spanning IT/OT boundaries
- Certificate Services (ADCS) in converged environments
- Network segmentation and zone/conduit architectures (ISA/IEC 62443)

## Physical Process Systems

- Liquefied Natural Gas (LNG) process simulation (student kit)
- PLC programming and I/O
- Industrial sensors and actuators
- Process control loops
